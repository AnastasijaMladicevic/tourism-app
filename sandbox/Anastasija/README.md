**Server**

Ovaj deo projekta je odradjen pomocu .NET verzije 8.0.


**Demo aplikacija**

U ovoj demo aplikaciji je implementirana simulacija placanja platnom karticom.
Korisnik unosi sledeće podatke:

Ime vlasnika kartice – moguce je uneti samo slova i razmake, nije dozvoljeno unosenje brojeva ili specijalnih znakova.

Broj kartice – moze se uneti tacno 16 cifara, nije moguće uneti bilo sta sto nije broj.

Datum vazenja kartice – moze se uneti samo vazeci mesec i godina

CCV kod – mora biti tacno 3 cifre.

Aplikacija vrsi sve potrebne validacije kako bi se sprecilo unosenje neispravnih podataka.
